## 초안을 만든 방법
워크플로 한 번(에이전트 10개): 사실 조사(약관용·처리방침용) + 법 요건 조사 → 두 문서 작성 → 3방향 검토(사실 일치 · 법적 위험 · 쉬운 말) → 검토 반영. 근거가 없는 정책은 지어내지 않고 `[운영자가 정할 것: …]` 로 남겼고, 명세에는 있지만 데모에 없는 장치는 `[서버 계획 — 출시 때 확인]`, 흔한 문장이지만 결정이 없는 것은 `[제안]` 이다. 법 조문은 일부만 원문과 대조했다(대조 못 한 곳은 '확인 필요').
